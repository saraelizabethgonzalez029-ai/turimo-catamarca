## Purpose

Provide visitors with a shared page to compare and learn about Laguna Blanca, Cuesta del Portezuelo, and El Rodadero beyond their catalog summaries.

## ADDED Requirements

### Requirement: Multi-destination overview
The system SHALL provide a public page that presents Laguna Blanca, Cuesta del Portezuelo, and El Rodadero.

#### Scenario: Visitor opens the overview
- **WHEN** a visitor opens the destination overview page
- **THEN** the visitor sees information for Laguna Blanca, Cuesta del Portezuelo, and El Rodadero

### Requirement: Destination details
The system SHALL show each destination's name, locality, category, representative image, and expanded description.

#### Scenario: Visitor compares destinations
- **WHEN** a visitor reviews the overview page
- **THEN** the visitor can identify the required information for each of the three destinations

### Requirement: Catalog return
The system SHALL provide a visible control that returns the visitor to the tourism catalog.

#### Scenario: Visitor returns to the catalog
- **WHEN** a visitor selects the return control
- **THEN** the system navigates to the tourism catalog home page

### Requirement: Responsive overview access
The system SHALL keep the destination overview legible and accessible on mobile and desktop viewport sizes.

#### Scenario: Visitor uses a mobile device
- **WHEN** a visitor opens the overview on a narrow viewport
- **THEN** the destination information remains visible without requiring horizontal page scrolling
