## Why

Visitors need more than a short catalog summary to compare the remaining highlighted destinations in Catamarca. A shared overview page provides a simple way to learn about Laguna Blanca, Cuesta del Portezuelo, and El Rodadero in one place.

## What Changes

- Add a public overview page for Laguna Blanca, Cuesta del Portezuelo, and El Rodadero.
- Present each destination with its image, locality, category, and expanded descriptive information.
- Include a visible link that returns visitors to the tourism catalog.
- Keep the overview usable on mobile and desktop screen sizes.

## Capabilities

### New Capabilities
- `destination-overview`: Public page that presents information for multiple selected tourist destinations in Catamarca.

### Modified Capabilities

- None.

## Impact

- Affected code: a new route under `app/` using existing image assets and sources.
- No API, database, authentication, or additional dependency is required.
