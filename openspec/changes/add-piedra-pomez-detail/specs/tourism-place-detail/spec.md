## Purpose

Provide visitors with a focused, practical overview of Campo de Piedra Pomez so they can better understand the destination before planning a visit.

## ADDED Requirements

### Requirement: Campo de Piedra Pomez detail page
The system SHALL provide a public page dedicated to Campo de Piedra Pomez.

#### Scenario: Visitor opens the detail page
- **WHEN** a visitor opens the Campo de Piedra Pomez detail page
- **THEN** the visitor sees a page clearly identified as Campo de Piedra Pomez

### Requirement: Destination information
The system SHALL show a representative image, expanded description, location, and practical visit recommendations for Campo de Piedra Pomez.

#### Scenario: Visitor reads destination details
- **WHEN** a visitor views the Campo de Piedra Pomez detail page
- **THEN** the visitor can identify the destination's landscape, its location in El Penon, and visit recommendations

### Requirement: Return to catalog
The system SHALL provide a visible control that returns the visitor from the detail page to the tourism catalog.

#### Scenario: Visitor returns to the catalog
- **WHEN** a visitor selects the return control on the detail page
- **THEN** the system navigates to the tourism catalog home page
