## Purpose

Provide visitors with a focused introduction to Laguna Blanca so they can understand its protected high-altitude landscape before planning a visit.

## ADDED Requirements

### Requirement: Laguna Blanca detail page
The system SHALL provide a public page dedicated to Laguna Blanca.

#### Scenario: Visitor opens the detail page
- **WHEN** a visitor opens the Laguna Blanca detail page
- **THEN** the visitor sees a page clearly identified as Laguna Blanca

### Requirement: Laguna Blanca information
The system SHALL show a representative image, expanded landscape description, location, and practical visit recommendations for Laguna Blanca.

#### Scenario: Visitor reads destination details
- **WHEN** a visitor views the Laguna Blanca detail page
- **THEN** the visitor can identify its protected landscape, location in Belén, and visit recommendations

### Requirement: Catalog return
The system SHALL provide a visible control that returns the visitor from the detail page to the tourism catalog.

#### Scenario: Visitor returns to the catalog
- **WHEN** a visitor selects the return control on the detail page
- **THEN** the system navigates to the tourism catalog home page
